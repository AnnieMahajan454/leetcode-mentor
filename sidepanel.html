How to use

  1. Understand: the problem in plain words, with no spoilers.
  2. Hint: one nudge at a time (up to 4). Try it yourself in between.
  3. Build logic: brute force → key insight → optimized, with the why behind every step.
  4. Topics & traps: every concept from scratch, plus common interview mistakes.
  5. Write code: a commented solution with a line-by-line why.
  6. Review my code: reads your editor, finds bugs and shows a failing input.

Ask anything below, e.g. "why do we cast to long here?"

AI-assisted interview

  1. Set a time limit and press Start.
  2. Solve the problem in the LeetCode editor. The chat below is your AI assistant, like in an AI-allowed coding round.
  3. Every prompt you send is logged with its time.
  4. Press Finish & get feedback for a scorecard: problem solving, how well you used the AI, code quality, correctness and a hire verdict.

Tip: specific questions ("what edge case does my loop miss?") score better than "give me the answer".

Settings

Free, no credit card: aistudio.google.com/apikey → “Create API key”. It's stored only in this browser.

“Flash” models give the best explanations on the free tier. If you hit rate limits often, pick a “flash-lite” model.

For hints, code reviews and follow-ups, the mentor may look up your recent LeetCode submissions for this problem (status, failing test, code) to personalise its answer. Turn this off to keep them private.

Privacy: on Gemini's free tier, Google may use prompts to improve its models. Only the problem text, your questions, your code (when you click Review) and, if the option above is on, your past submissions are sent.
